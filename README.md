# Basement × Superga

Presentazione interattiva per Superga srl, pubblicata con GitHub Pages.

- `index.html`: tutta la presentazione. I testi e i percorsi delle immagini sono nel blocco JSON `<script id="content">`.
- `assets/`: immagini e video.
- **Video prodotto:** aggiungere il file come `assets/video-prodotto.mp4` (H.264, meno di 100 MB).

## Modificare
Aprire il sito aggiungendo `#edit` all'indirizzo (o aprire `index.html` in locale), cliccare ✎, modificare testi e immagini, poi "Scarica HTML" e sostituire `index.html` nel repository.
Le immagini caricate così finiscono dentro l'HTML: per foto pesanti e video conviene metterle in `assets/` e scrivere il percorso nel JSON.
